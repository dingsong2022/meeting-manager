개인정보처리방침 (Privacy Policy)

최종 수정일: 2026-10-13

1. 앱 개요

yshinchon meeting manager(이하 "앱")는 작성자 본인이 개인 PC에서만 실행하는 업무 자동화 도구입니다.

2. 접근하는 Google 데이터

  • Google Calendar (읽기 전용): '기획회의' 일정의 날짜와 시각 확인
  • Google Drive (읽기 전용 / 앱이 만든 파일): 회의록 문서 찾기 및 PDF 저장
  • Google Docs: 회의록 문서 생성 및 서식 정리

3. 데이터 처리 및 보관

모든 데이터는 사용자 본인의 PC에서만 처리되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다. 인증 토큰은 사용자 PC에만 저장됩니다.

4. Google API 서비스 사용자 데이터 정책 준수

이 앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API Services User Data Policy를 준수합니다.

5. 권한 철회

Google 계정 → 서드파티 앱 액세스에서 언제든지 이 앱의 접근 권한을 철회할 수 있습니다.
